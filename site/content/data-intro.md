# Data

Everything here is built from the Form ADV extracts the SEC publishes each month for investment advisers. There are two each month: one for registered advisers, which carries the assets, headcount and client items a panel needs, and one for exempt reporting advisers, who file a truncated form.

On September 10, 2026 the SEC's index listed 16 of these files. Older editions are delisted, but most remain on the SEC's servers at their original addresses: of 42 delisted files requested that day, 41 were still there and one returned a 404. The project keeps its own checksummed copy of every file it has recovered and records each one below, with whether it came from the index or from a delisted address. A month with no row is a gap in this archive.

Each file is classified by what it contains rather than what it is called, and dated by the latest filing inside it. The two can disagree: the registered-adviser file posted on September 2, 2025 holds the same roster as the one posted a month earlier, with no filing after July 31, 2025. A dagger (†) marks every file whose data does not advance past the previous file of the same kind.

The files themselves are not redistributed here; each name links to the SEC's copy. The two files compared in [the new-registrant panel](/adv) are in bold. The complete manifest, with full checksums, is [manifest.csv](/data/manifest.csv).
